Usage at a glance

Click the menu-bar icon and see the usage windows and credit balances of all your AI accounts in one place. Every limit gets a bar with how much you have used and when it resets ("in 2 h 14 m", or the date), plus the remaining amount where the provider meters by money.

Set it up once

Add an account per provider and TokenMeter keeps all readings fresh in the background, with sensible back-off when a provider rate-limits you. Show or hide secondary windows (a whole week, a billing month, a scoped session) per account, and get a notification before a window runs out.

Settings: Ollama Cloud and Claude accounts, add more, sign in, or remove.

Providers and authentication

Nineteen providers, one popover. Use an API key, sign in with a device code, or let TokenMeter borrow the login your coding tool already has.

ProviderHow it authenticates
Claude Borrows the login of Claude Code, the official CLI. TokenMeter has no Claude sign-in of its own and never stores or refreshes Claude tokens — see ADR 0001.
Codex Sign-in inside TokenMeter (device-code browser flow). One click in Settings' "+" menu, then approve in the browser — see ADR 0003.
GitHub Copilot Sign-in inside TokenMeter (GitHub device-code browser flow). Reads the monthly AI-credit allowance; Free plans show chat and completion limits, and org-managed seats show their plan plus any personal credits GitHub reports. The token stays in your Keychain.
Nous Portal Sign-in inside TokenMeter (device-code browser flow). Same flow as Codex; tokens are stored and rotated in the Keychain.
Ollama Cloud API key, pasted in Settings. Create a key on your Ollama dashboard and add it as an account.
Venice.ai Admin API key, pasted in Settings. Inference keys cannot read billing. Create an Admin key in Venice's API settings; TokenMeter draws the daily DIEM epoch (refreshed at 00:00 UTC) as a progress bar and lists bundled, earned and USD credit balances.
Z.ai API key, pasted in Settings. Reads the GLM Coding Plan's 5-hour and weekly token quotas plus the monthly web-search/reader call quota.
xAI Management API key + team ID, pasted in Settings. Reads the team's prepaid USD credit balance (and the postpaid remaining estimate when returned). Inference keys are rejected; create a Management key in the xAI Console.
Cursor Borrows Cursor's local login (desktop state.vscdb or the cursor-agent Keychain item). Reads the billing-cycle percentage plus Auto and API sub-windows. Tokens are read per fetch and never stored or refreshed.
OpenCode API key, pasted in Settings. Reads OpenCode Go/Zen rolling 5-hour, weekly and monthly usage percentages.
Alibaba Cloud Coding Plan API key (sk-sp-…) + region, pasted in Settings. Reads the Coding Plan's 5-hour, weekly and monthly request quotas from the Model Studio console endpoint.
Gemini Borrows the Gemini CLI login (~/.gemini/oauth_creds.json). Reads per-model remaining quota through Google's Code Assist API. Tokens are refreshed in memory only and never stored; Google has retired the free Code Assist tier.
Antigravity Borrows the Antigravity / agy login (CLI token file or Keychain). Reads per-model remaining quota. Tokens are refreshed in memory only and never stored.
MiniMax API key + region (Global or China), pasted in Settings. Reads the Token Plan's current session window from /v1/token_plan/remains.
Kimi Borrows the Kimi Code login (~/.kimi/credentials/kimi-code.json). Reads the plan usage plus each windowed limit (5-hour, weekly, …). Tokens are refreshed in memory only and never stored.
Synthetic API key, pasted in Settings. Reads the rolling 5-hour request limit, weekly budget and optional legacy subscription/search quotas.
DeepSeek API key, pasted in Settings. Reads the account's USD/CNY balance (total, granted and topped-up amounts as reported).
Mistral Admin API key, pasted in Settings. Reads the Organization's monthly spend against its spend limit. Admin keys require an Enterprise plan; standard inference keys are rejected.
Xiaomi MiMo Browser cookies, pasted in Settings. Reads the console balance plus Token Plan credits from platform.xiaomimimo.com. Copy the Cookie header while signed in; the required cookies are api-platform_serviceToken and userId.

Privacy

TokenMeter talks only to the providers you configure, and:

  • Secrets never leave your Mac — provider tokens and API keys live only in the macOS Keychain, never in a settings file.
  • Borrowed logins are never stored: Claude Code, Cursor, Gemini CLI, Antigravity and Kimi Code tokens are read at fetch time, used for the request, and discarded.
  • No telemetry, no analytics, no update phone-home you can't turn off.
