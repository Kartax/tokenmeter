The popover: every window and credit balance, refreshed automatically.

Usage at a glance

Click the menu-bar icon and see the usage windows and credit balances of all your AI accounts in one place. Each account shows how much of every window's limit you have used and when it resets ("in 2 h 14 m", or the date), plus remaining credits where the provider meters by money.

Set it up once

Add an account per provider and TokenMeter keeps all readings fresh in the background, with sensible back-off when a provider rate-limits you. Show or hide secondary windows (a whole week, a billing month, a scoped session) per account, and get a notification before a window runs out.

Settings: your accounts, add more, sign in, or remove.

Providers and authentication

ProviderHow it authenticates
Claude Borrows the login of Claude Code, the official CLI. TokenMeter has no Claude sign-in of its own and never stores or refreshes Claude tokens — see ADR 0001.
Codex Sign-in inside TokenMeter (device-code browser flow). One click in Settings' "+" menu, then approve in the browser — see ADR 0003.
Nous Portal Sign-in inside TokenMeter (device-code browser flow). Same flow as Codex; tokens are stored and rotated in the Keychain.
Ollama Cloud API key, pasted in Settings. Create a key on your Ollama dashboard and add it as an account.

Privacy

TokenMeter talks only to the providers you configure, and:

  • Secrets never leave your Mac — provider tokens and API keys live only in the macOS Keychain, never in a settings file.
  • Claude tokens are never stored: they are read from Claude Code at fetch time, used once, and discarded.
  • No telemetry, no analytics, no update phone-home you can't turn off.
